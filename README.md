Blog Web Application

A modern and responsive blog web application built to create, manage, and share blog posts easily. This project provides a clean user interface, authentication system, blog management features, and responsive design for all devices.

Features


1.User Authentication (Login / Register)

2.Create, Edit, and Delete Blog Posts

3.Rich Text Blog Editor

4.Responsive Design

5.Search and Filter Blogs

6.User Profile Management

7.Comment System

8.Like and Share Functionality

9.Admin Dashboard

10.Dark / Light Mode Support
